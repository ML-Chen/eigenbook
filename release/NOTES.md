# Eigenbook 1.1.48

Install `eigenbook.apk` on Android 8.0 or newer. Installed copies update themselves: new lessons download in the background, and app changes ask before installing.

`book.html` is the whole book as one offline page for any browser.

This release: 51 lessons; formulas in the attention lesson are now typeset LaTeX (the other lessons follow in the next release).
